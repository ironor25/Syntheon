# Syntheon: Research Tool for LLM API and Web Crawling

Syntheon is a research tool designed to leverage large language models (LLMs) and web crawling capabilities to gather and analyze data. It integrates LLM APIs and uses `crawl4ai` to crawl the web, enabling efficient data collection and comparison.

## Features

- **LLM Integration**: Supports advanced LLMs like `ChatOllama` for natural language processing tasks.
- **Web Crawling**: Uses `crawl4ai` to extract and process data from the web.
- **API Development**: Provides a framework to build APIs for research and data analysis.
- **Task Automation**: Automates tasks such as comparing API pricing, analyzing trends, and more.
